# Homehood Specs

This repository contains the specifications for Homehood.

A specification describes what a feature must do. It does not describe how to build the feature. Use the specs to agree on the work before you write code.

## Contents

Each spec is a Markdown file in this repository.

## Write a spec

1. Create a branch from `main`.
2. Add a Markdown file for the new spec.
3. State the problem the spec solves.
4. Describe the expected behavior in short, clear steps.
5. Open a pull request.

## Review a spec

- Make sure the spec is clear and complete.
- Make sure each requirement can be tested.
- Ask questions in the pull request comments.
- Merge the pull request when the team agrees.

## Change a spec

Change a spec with a pull request. Explain the reason for the change in the pull request description.
